Architecture Decision Records

Design Decisions

A public log of the team's architecture decisions - context, options considered, choice and reasoning. Documented so the project trajectory remains readable for new members, RoboSub judges, and future iterations.

[01] Active decisions 8 ADR
  • ADR-009 2026-03-12 ACCEPTED

    Mission planner: Behavior Tree + Python

    The mission planner must sequence competition tasks (Gate -> Slalom -> Bins -> Octagon), react to events (lost detection, timeout, safety), and stay serviceable across the team's full range of experience levels. The choice covers both the control paradigm (FSM vs Behavior Tree) and the implementation language (Python vs C++).

    Decision: Behavior Tree in py_trees (Python), with separate ROS 2 nodes per skill.
  • ADR-005 2026-01-15 ACCEPTED

    Distance estimation: triangle similarity as baseline + SolvePnP as primary

    Distance estimation to competition gates from a **single camera** - critical for navigation in RoboSub tasks without a DVL.

    Decision: Triangle similarity as baseline + SolvePnP as primary (after YOLOv8-pose fine-tuning)
  • ADR-007 2025-12-05 ACCEPTED

    Distributed vision: dedicated RPi per camera vs centralized

    Visual perception architecture - YOLOv8 inference on 4 camera streams. Centralized on Jetson Orin vs distributed (one RPi 5 per camera).

    Decision: Distributed - one RPi 5 per camera, Jetson aggregates detections over Ethernet
  • ADR-006 2025-11-10 ACCEPTED

    Kill switch: mechanical vs MOSFET

    Safety - how to physically cut thruster power on a signal from the safety diver / referee.

    Decision: Mechanical Talamex 300 A kill switch
  • ADR-004 2025-09-20 ACCEPTED

    Heavy compute: NVIDIA Jetson Orin Nano

    Compute unit choice for heavy AI workload - real-time YOLO inference, mission planning, and possibly path planning.

    Decision: NVIDIA Jetson Orin Nano (8 GB)
  • ADR-003 2025-09-15 ACCEPTED

    Thruster layout: 6 vs 8 in vector configuration

    Thruster count and layout for the first BlueSpark vehicle - critical for maneuverability, cost, and torque-allocator scope.

    Decision: 8 thrusters in the BlueROV2 Heavy vector configuration: 4 horizontal (45° vector arms) + 4 vertical.
  • ADR-002 2025-07-01 ACCEPTED

    Detection: YOLO + 3D pose estimation

    Vision pipeline for RoboSub tasks (gates, buoys, markers).

    Decision: YOLO + custom 3D pose estimation from camera intrinsics
  • ADR-001 2025-06-01 ACCEPTED

    ROS 2 Humble as framework

    Choice of main robotics framework for the BlueSpark stack.

    Decision: ROS 2 Humble
