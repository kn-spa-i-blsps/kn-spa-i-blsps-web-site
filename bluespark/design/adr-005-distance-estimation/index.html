ADR-005 2026-01-15 · ACCEPTED

Estymacja odległości: triangle similarity jako baseline + SolvePnP jako primary

Kontekst

Estymacja odległości do bram konkursowych z jednej kamery - kluczowa dla nawigacji w zadaniach RoboSub bez DVL.

Opcje rozważone
  • Triangle similarity (focal length ratio)
  • SolvePnP (3D pose z keypointów)
  • Stereo vision (2 kamery)
  • Active sensing (sonar / DVL)
Decyzja

Triangle similarity jako baseline + SolvePnP jako primary (po dotrenowaniu YOLOv8-pose)

Dlaczego

Single-camera setup minimalizuje koszt i complexity. Triangle similarity działa bez treningu modeli - gotowy fallback. SolvePnP daje pełne 3D pose (odległość + orientacja), kluczowe dla precyzyjnego pozycjonowania.

Decyzja podjęta po testach w repo BlueSpark-autonomy.

Dlaczego nie stereo

  • Stereo wymaga dwóch dokładnie skalibrowanych kamer
  • Kalibracja stereo pod wodą jest znacznie trudniejsza niż mono
  • 2× więcej processing pipeline

Dlaczego nie sonar / DVL

  • DVL kosztuje 10-30k zł (poza budżetem sezonu 01)
  • Sonar wymaga dedykowanego computera i processing

Konsekwencje

  • Wymagana kalibracja każdej kamery - Charuco board (lepsze niż chessboard)
  • Triangle similarity działa od pierwszego dnia - prosty fallback gdy SolvePnP nie zwróci wyniku
  • SolvePnP wymaga modelu YOLOv8-pose wytrenowanego na bramach konkursowych - prace w toku
  • Distance + orientation z SolvePnP umożliwia mission planner do precyzyjnego pozycjonowania przed przelotem przez bramę
